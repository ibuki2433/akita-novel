เช้าที่เงียบสงัด สายลมหนาวกรีดผ่านช่องว่างระหว่างตึกสูงของมหาวิทยาลัยคามิซึจิ ส่งเสียงหวีดหวิวราวกับเสียงกระซิบ บนดาดฟ้าของนักเรียน มีชายร่างสูงในชุดสีดำสนิทหยัดยืนท้าแรงลม ชายเสื้อคลุมสะบัดพลิ้วไสว

เงาปริศนา : “มหาลัยนี้งั้นเหรอ…? สถานที่ที่มีผู้ใช้อาคิตะซ่อนตัวอยู่หลายคน…”

น้ำเสียงเย็นเยียบเปรยออกมาเบา ๆ สายตาคมกริบจ้องมองลงไปยังแสงไฟด้านล่าง

เงาปริศนาเปิดสมุดบางอย่างออกมา พร้อมมีรูปเฟียในสมุด

เงาปริศนา : “อืมม… ฉันว่าน่าจะมีมากกว่านี้นะ”

เขายกยิ้มมุมปากอย่างเย็นชา :)

เงาปริศนา : “ได้เวลาไปล่าตัวแล้วสินะ”

บรรยากาศยามกลางวัน

ในเวลาเดียวกัน — ที่ลานหน้าคณะ

อิสึกิ คามิซึจิ นั่งขมวดคิ้วจดจ่ออยู่กับหน้าจอสมาร์ทโฟน แสงสีฟ้าจากจอสะท้อนในนัยน์ตาที่ดูเหนื่อยล้า พาดหัวข่าวเด่นหราบนหน้าฟีดระบุถึงเหตุการณ์สะเทือนขวัญ: จำนวนผู้เสียชีวิตพุ่งสูง! ผู้ใช้อาคิตะออกอาละวาดหนัก ล่าเหยื่อไม่เลือกหน้า

เฟีย เพื่อนสนิทของอิสึกิ เดินมาพร้อมถอนหายใจแรง

เฟีย : “เฮ้อ… ช่วงนี้มีแต่พวกใช้พลังอาคิตะไปก่อเรื่อง… น่ารำคาญจริงๆเลยนะ”

อิสึกิ : “นายก็เปีนผู้ใช้อาคิตะเหมือนกันไม่ใช่เหรอ ฮ่าๆๆๆๆ”

เฟีย : “ก็ใช่เว้ย!! แต่ฉันไม่ได้ล่าคนมั่วซั่วแบบพวกนั้นซะหน่อย! ผู้ใช้อาคิตะอย่างฉันก็เปีนมนุษย์เหมือนกับทุกคนนะโว๊ยยยย!!!”

เฟียตอบกลับอิสึกิแบบเพื่อนสนิทคุยกันพร้อมกับแซว

อิสึกิยิ้มบาง ๆ พร้อมกับหัวเราะ

อิสึกิ : "เห้ออ ก็นะ"

อิสึกิ : “งั้น… หลังเลิกเรียนเย็นๆไปกินข้าวกันไหม? อยากกินราเม็งร้านลุงไอซ์อะ”

เฟีย : “ได้ดิ ไปด้วยอยู่แล้ว! ฉันเองก็อดใจที่จะกิน มิโซะ บัตเตอร์ ราเม็ง ของร้านลุงไอซ์จะแย่อยู่แล้ว โคตรอร่อยเลย!!!”

ร่างหนึ่งตกลงมาจากอาคารสูงตรงหน้าทั้งคู่ เศษฝุ่นกระจายจนต้องยกมือบังใบหน้า อิสึกิกับเฟียมองมาที่เงาตรงหน้า

ผู้ใช้อาคิตะปริศนา : “ไง… หนุ่มน้อยผู้ใช้อาคิตะ”

เขาเปิดสมุดเล่มหนึ่งขึ้นอย่างช้าๆ มองดูในนั้นแล้วแสยะยิ้ม

ผู้ใช้อาคิตะปริศนา : “ไม่ผิดตัวแน่…”

จากนั้นไม่พูดพร่ำ — ทำเพลง เขาพุ่งเข้าหาทั้งสองด้วยความเร็วเหนือมนุษย์ เฟียสะบัดดาบยาวออกมาขวางทันที

เฟีย : "คนที่แกต้องสู้คือ ฉัน ต่างหาก!!!”"

เฟีย vs ผู้ใช้อาคิตะ

โดยไม่พูดพร่ำทำเพลง อีกฝ่ายวาดมือไปทางด้านหลัง คว้าด้ามดาบสีดำสนิทที่แสกออกมา เร็วสูงจนเกิดเสียง เชิ้ง! บาดแก้วหู

เฟีย : “ระวังนะอิสึกิ… ดูจากทรงแล้วเจ้านี่คงจะไม่ธรรมดา—”

เฟียบอกเพื่อนสนิทตัวเองและพร้อมกับปลดปล่อยพลังอาคิตะของตัวเองออกมา ร่างกายของเขาถูกคลุม ก่อนที่ดาบเล่มยาวของเขาจะปรากฏขึ้นในมือ หลังจากนั้นผู้ใช้อาคิตะก็พุ่งเข้าหาเฟีย เคร้ง!! เคร้ง!! เคร้ง!! เคร้ง!! แปร๊ง!!! เคร้ง!! แปร๊ง!!! เสียงดาบกระทบกันอย่างรุนแรงจนเกิดประกายไฟกระเด็นไปทั่ว เขาวาดเหวี่ยงดาบเข้าใส่ในมุมอาวุธที่หลากหลาย แต่ผู้ใช้อาคิตะคนนั้นกลับรับมือได้อย่างสุขุม ใช้เพียงข้อมือเบี่ยงทิศทางดาบของเฟียออกไปอย่างง่ายดาย เคร้ง!! เคร้ง!! เคร้ง!! การปะทะยังคงดำเนินต่อไปอย่างต่อเนื่อง เสียงเหล็กกล้ากระทบกันรัวเร็วราวกับเสียงจังหวะดนตรีที่บ้าคลั่ง เฟียเริ่มรู้สึกได้ถึงแรงสั่นสะเทือนที่ส่งผ่านดาบมาถึงแขน... แรงปะทะของอีกฝ่ายหนักหน่วงกว่าที่คิดมาก (เฟียคิดในใจ):”หนักหน่วงมาก… ถ้ารับการโจมตีแบบนี้นานๆไป แขนอาจจะหักเลยก็ได้”

เคร้ง!! เคร้ง!! แปร๊ง!!! เคร้ง!! แปร๊ง!!! ดาบที่สี่ถูกฟันลงมาด้วยแรงมหาศาล เฟียพยายามใช้ดาบรับไว้ แต่มันกลับรุนแรงจนทำให้เขาเสียหลักถอยหลังไปหลายก้าว

ผู้ใช้อาคิตะปริศนา : “มีฝีมือแค่นี้เองเหรอ… น่าผิดหวังจริงๆ”

ผู้ใช้อาคิตะพูดยั่ว พร้อมกับพุ่งตัวเข้าหาเฟียด้วยความเร็วที่เหนือกว่าเดิม แปร๊ง!!! แปร๊ง!!! แปร๊ง!!!

เฟียพยายามฝืนทรงตัวและยกดาบขึ้นรับ แต่ทว่า... ความเร็วของอีกฝ่ายนั้นรวดเร็วจนเขามองตามแทบไม่ทัน เคร้ง!! เคร้ง!!

ดาบของมันฟันลงมาที่หัวไหล่ เฟียเบี่ยงตัวหลบได้ฉิวเฉียด แต่ดาบกลับทิ้งรอยแผลตื้นๆ ไว้บนไหล่เสื้อ

เฟีย : “ชิ…”

แต่ผู้ใช้อาคิตะแสยะยิ้มก่อนจะพลิกตัวตวัดขาเตะเข้าที่ชายโครงของเฟียอย่างจัง ผัวะ!! ตุ้มมม!! เฟียกระแทกพื้นอย่างรุนแรงด้วยแรงเตะมหาศาล เสียงกระดูกลั่นดัง กร๊อบ!! พร้อมกับที่เขากระอักเลือดคำโตออกมาเปรอะเปืือนพื้นซีเมนต์

เฟีย : “อึก… แข็งแกร่ง… กว่าที่คิด… บ้าเอ๊ย…”

เขากล่าวออกมาอย่างยากลำบาก ขณะที่พยายามพยุงตัวขึ้นจากพื้น

ผู้ใช้อาคิตะปริศนา : “หึ… อ่อนแอ… ผู้ใช้อาคิตะอย่างแกมีสิทธิ์แค่เปีนเหยื่อให้ฉันล่าก็เท่านั้นแหละ”

มันก้าวเดินเข้ามาหาเฟียช้าๆ อย่างผู้ชนะ

เสียงดาบกระทบกันดัง เคร้ง!! เคร้ง!!

อีกฝ่ายใช้ดาบเหมือนกัน แต่แรงและความเร็วเหนือกว่า ผู้ใช้อาคิตะเข้าหาเฟียแล้วใช้ดาบฟันเข้าอีกครั้ง

เคร้ง!! เคร้ง!! ฟันดาบอย่างต่อเนื่อง แต่เฟียเสียจังหวะ เฟียถูกเตะเข้าเต็มหน้าอก

เสียงปลายรองเท้ากระทบพื้นดัง กึก

เปลวไฟสว่างวาบออกจากคฑาของเธอ ผู้ใช้อาคิตะยิ้มบางๆ

ไอร่า : “แกมีภารกิจลักพาตัวผู้ใช้อาคิตะมือใหม่สินะ!?”

ผู้ใช้อาคิตะ : “ก็รู้อยู่แล้วนี่… นั้นแหละคือจุดประสงค์”

ไอร่า : “และฉันเองก็ขัดจุดประสงค์ของแกเช่นกัน…”

ไอร่า vs ผู้ใช้อาคิตะ

เธอฟาดคฑาใส่เขา แต่ชายคนนั้นใช้มือรับเอาไว้ได้

ไอร่า : “ฉันชนะมันเพราะมันเสียท่าให้ แต่มันหนีไปได้… ช่างมันก่อนเถอะ” “เพื่อนนาย… ตายแล้วนะ ฉันเสียใจด้วย เขาโดนแทงคอสี่จุด… ต่อให้เปีนผู้ใช้อาคิตะสูงๆ ก็คงรับแผลแบบนั้นไม่ไว้หรอก…”

อิสึกิหันไปเห็นร่างไร้ชีวิตของเฟีย หัวใจเหมือนถูกฉีกออกช้าๆ ทั้งเศร้า ทั้งแค้น ทั้งช็อก

อิสึกิ : “…เฟีย…”

เขากำมือแน่นจนสั่น

อิสึกิได้หันมาถามไอร่า

อิสึกิ : “แล้ว… เธอกับหมอนั่นรู้จักกันเหรอ…?”

ไอร่าหยุดคิดก่อนตอบ

ไอร่า : “เรื่องมันยาว… เอาเปีนว่า มาที่กลุ่มของฉันก่อนเถอะ เรามีนักรักษาที่เก่ง อาการนายไม่ปกติ อย่าฝืนเลย”
